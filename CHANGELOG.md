# Changelog

## 0.1.1 — 2026-11-25

- First stable release following successful live-client user verification.
- Add CurseForge project metadata for addon identification.
- Add tested automatic GitHub and CurseForge releases, including Lua tests and
  installation ZIP validation before publication.
- No runtime layout changes compared with the initial beta.
- Broader combat, Edit Mode and resolution coverage remains ongoing.

## 0.1.0 — 2026-11-25 (early beta)

- Standalone native buff/debuff layout with no dependency on a private UI addon.
- Vertical/horizontal layout, wrapping, spacing, scale and separate offsets.
- German/English options window, Settings entry and `/fba` / `/etzsauras`.
- Account-wide SavedVariables with validation and defaults.
- Combat deferral, guarded native layout hooks and restore-on-disable.
- Automated Lua 5.1 tests; live-client validation remains pending.
